# 한글 화학식 도우미

화학식·반응식을 한글(HWP)에 붙여 넣고, 분자량·용액 계산, DNA·단백질 서열 분석, 생체분자 사전, 생명과학 수식 모음, 진로·최신 논문 소식을 볼 수 있는 학습용 웹앱입니다.

## 설치 방법
1. 이 폴더의 파일을 GitHub 저장소에 그대로 올립니다 (index.html, manifest.webmanifest, sw.js, icons 폴더).
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save.
3. 1~2분 뒤 나오는 주소(https://아이디.github.io/저장소이름/)를 열고 설치합니다.
   - 안드로이드 · 크롬/엣지(노트북): 위 메뉴의 `⬇ 앱 설치` 버튼, 또는 주소창 옆 설치 아이콘
   - 아이폰 · 아이패드: Safari 공유 버튼 → `홈 화면에 추가`

## 참고
- Gemini API 키는 각자 기기의 브라우저에만 저장됩니다. 키를 파일에 적어 올리지 마세요.
- 최신 논문은 Europe PMC, PubMed 공개 API에서 불러옵니다.
